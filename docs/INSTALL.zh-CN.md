# 库存手记 · 巨魔安装说明

适用于已经安装并可正常使用 TrollStore（巨魔）的设备。此 IPA 的最低系统是 iOS 14.0；这不代表任意 iOS 版本都支持巨魔，请以 [TrollStore 官方说明](https://github.com/opa334/TrollStore)为准。

## 第一次安装

1. 在 Safari 打开目前使用的库存网站，在“我的”中导出 **JSON 备份**，保存到“文件”或网盘。确认文件存在；Excel 不能代替恢复用 JSON。
2. 从本仓库的 **Releases** 下载 `SkincareInventory-1.0.1-TrollStore.ipa`。不要把同页源码 ZIP 当成安装包。
3. 在 TrollStore 点右上角“＋”，选择 IPA 并安装；或者从“文件”把 IPA 分享给 TrollStore。
4. 打开桌面的“库存手记”，联网等待网页加载。首次为空库存属于正常情况，Safari 的数据不会自动进入 App。
5. 在 App 的“我的 → 导入备份”选择之前保存的 JSON。阅读覆盖确认后导入，再核对商品数量、批次、日期和使用记录。
6. 添加一条可识别的测试记录，完全关闭 App 后重新打开，确认记录仍存在；随后移除测试记录。

导入会替换 App 当前库存，请先备份 App 中已有的数据。无效或不兼容的 JSON 应提示失败并保留当前库存。

## 导出与分享到网盘

在 App 里导出 JSON 或 Excel 后，使用系统界面保存到“文件”，或交给设备已经安装的网盘应用。网盘是否出现在分享列表由 iOS 和该网盘应用决定。

网页显示的“最近备份”或导出提示沿用网站现有行为，可能在生成文件或唤起分享时更新，**不能证明网盘已上传成功**。请到“文件”或网盘核对实际文件；取消分享后不要据此认为已有可恢复备份。

## 更新 App

1. 在当前 App 中导出 JSON 并确认保存成功。
2. 下载新版本 IPA，在 TrollStore 中选择**覆盖安装/更新现有 App**，保持 Bundle ID `io.github.saimilai.skincareinventory`。
3. 不要先卸载旧版。相同 Bundle ID 的覆盖安装通常会沿用数据容器，但真实设备行为仍需核对，不能保证没有任何数据风险。
4. 更新后检查库存；若数据缺失，使用第一步的 JSON 恢复。

网页日常更新通常不需要重装 IPA。只有原生文件适配等封装能力变化时才需要新版安装包。App 不会自动更新自身。

卸载前务必备份。通过 TrollStore 卸载 App 可能删除其本地库存；重新安装不会自动找回。请使用 TrollStore 的管理入口卸载，不要仅依赖主屏幕图标操作。

## 联网失败

打开或重新加载依赖原网站可访问。若看到网络错误，请恢复网络后点重试；不要以清空 App 数据、卸载或反复导入作为网络故障的处理方法。App 与 Safari 的存储独立，因此改用 Safari 打开也不会自动看到 App 刚录入的库存。

## 核对下载与验收

Release 附带的 `SHA256SUMS.txt` 记录安装包和报告的 SHA-256。在电脑上可用对应系统的哈希工具核对 IPA，排除下载损坏；哈希一致不等于已通过实机测试。

安装后建议核对：启动、录入与关闭后重开、JSON 导出/恢复、Excel 保存、取消分享、断网重试。安装包的自动验收覆盖构建结构与模拟器；**用户设备上的 TrollStore 安装、备份分享和覆盖更新仍需实际验证**。
